SCAM SIGNAL / PYTHON × OLLAMA

可疑訊息分類器

貼上一段可疑簡訊或私訊，用本地語言模型找出警訊，整理成四個固定欄位，方便閱讀和後續處理。

怎麼執行 ↓看輸出 ↓

01 做了什麼

Python 將訊息和 JSON Schema 送給本機 Ollama 的 /api/chat，由 Qwen2.5 產生結構化輸出。程式檢查欄位、字串和允許值後，再印出 JSON。

risk
風險等級，分為高、待查證、低
category
可能的詐騙類型，例如投資或假客服
reason
判斷所依據的訊息線索
next_step
可以採取的查證行動

02 怎麼執行

先安裝 uv 和 Ollama。開啟 Ollama 應用程式，或在另一個終端機執行 ollama serve。接著在專案目錄執行下列指令。

ollama pull qwen2.5:1.5b
uv sync --locked
uv run --locked python classify.py "【銀行通知】您的銀行帳戶即將停用，請立即回傳簡訊驗證碼以解除限制。"

03 執行結果

以下是本機 Qwen2.5 1.5B 實跑後的原始 JSON。示範訊息為虛構內容。

【銀行通知】您的銀行帳戶即將停用，請立即回傳簡訊驗證碼以解除限制。
{
  "risk": "high",
  "category": "銀行／金融",
  "reason": "銀行停用帳戶通常需要通過簡訊驗證碼進行確認，此類通知應當謹慎處理。",
  "next_step": "請勿點擊任何連結或提供敏感信息，建議聯繫官方客服了解真實情況。"
}

人工檢視：模型將訊息判為高風險，但理由對銀行驗證流程的推測缺乏根據。這則訊息可直接觀察到的警訊是它要求收件人回傳簡訊驗證碼。

04 AI 使用說明

ChatGPT 協助規劃、撰寫程式、建立示範資料與整理作品頁。本地 Qwen2.5 負責分析訊息，分類結果僅供初步篩查。

預設執行無需金鑰。若日後改用雲端模型，金鑰放在本機 .env。GitHub Actions 只發布靜態作品頁，模型推論在使用者本機執行。
